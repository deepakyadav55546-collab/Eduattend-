# EduAttend Universal Education Specification

EduAttend = All-in-One Education Management Platform.

## Institute types
- School
- College / University
- Coaching
- Tuition
- English / Language Institute
- Computer / IT Institute
- Skill / Training Center
- Other

## Shared modules
Authentication, institute settings, students/learners, teachers/faculty,
classes/sections/batches, attendance, courses/subjects, exams/assessments,
fees/payments, homework/assignments, timetable, notifications, reports,
dashboard.

## Type-specific terminology
- School: Class + Section
- College/University: Department + Course + Semester
- Coaching/Tuition: Batch + Subject + Schedule
- Language: Level + Batch + Course
- Computer/IT: Course + Module + Practical/Lab
- Skill Training: Program + Batch + Competency/Assessment
